# Sonsuz Merdiven Çıkma Programı

Bu program, insanlığın en büyük varoluşsal krizlerinden birini çözmek için tasarlanmıştır: **Sonsuza kadar merdiven çıkmak.**

## Neden Bu Program?

Çünkü hayatta bazen sadece çıkarsın. Çıkarsın çıkarsın çıkarsın. Ama hiç varamazsın. Bu program tam olarak bunu simüle eder. Abartılı bir şekilde. Ciddi bir şekilde. Ama aslında hiç ciddi değil.

## Nasıl Çalışır?

Python scriptini çalıştır. Sonsuza kadar "bir basamak daha" yazıp durur. Yorgunluk mesajları artar. Belki bir gün varırsın. Muhtemelen varmazsın.

## Kurulum

```bash
python merdiven.py
```

Hepsi bu. Başka hiçbir şey yok. Gerçekten.

## Uyarı

Bu program sizi sonsuza kadar merdiven çıkmaya zorlayabilir. Sorumluluk kabul etmiyoruz. Hatta sorumluluk diye bir şeyin varlığını bile sorguluyoruz.
